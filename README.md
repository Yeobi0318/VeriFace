# VeriFace

> **로컬 안면인식 인증 도구 (연구 · 교육용)** — 내 PC에서만 동작하는 오픈소스 얼굴 인증 프로그램

VeriFace는 웹캠으로 **본인을 인식**해, 얼굴로 잠금 해제되는 **암호 금고(Vault)** 와
빠른 본인 확인 기능을 제공하는 Windows 데스크톱 앱입니다. 모든 처리는 **오프라인**
으로 이뤄지며, 얼굴 이미지나 특징값은 PC를 벗어나지 않습니다. 인식을 수행하는 순간
에만 카메라와 AI 모델을 올리고, 끝나면 즉시 내려서 **대기 중 자원 사용이 거의 0** 입니다.

---

## ✨ 주요 특징

- **정확하고 강건한 인식** — OpenCV의 오픈소스 모델 **YuNet(검출) + SFace(인식)** 사용.
  SFace 임베딩은 얼굴의 안정적인 구조(눈 간 거리, 코·턱 형태 등)에 기반하므로
  **머리가 떡지거나, 머리를 깎거나, 안경을 벗어도** 동일인으로 잘 매칭됩니다.
  (등록 시 안경 착용/미착용을 모두 담으면 정확도가 더 올라갑니다.)
- **PC 분석 → 모델 자동 선정/설치** — `PC 분석` 버튼이 CPU/RAM/GPU를 점검해
  최적 프로파일(검출 해상도·샘플 수)을 고르고, 모델 설치 여부를 확인한 뒤
  **사용자 허가를 받아** OpenCV Zoo에서 모델(수 MB)을 내려받습니다.
- **효율 우선 설계** — 무거운 라이브러리는 세션 중에만 import. 카메라·모델은 세션이
  끝나면 `release()`/`close()` 로 반드시 해제. 백그라운드 상주 데몬·메모리 누수 없음.
- **안전한 저장** — 얼굴 **임베딩(벡터)만** 저장(원본 사진 저장 안 함), 금고와 템플릿은
  **Windows DPAPI**로 현재 사용자 계정에 묶어 암호화.
- **기초 라이브니스(위변조 방지)** — 고개 돌리기/끄덕이기 등 능동 챌린지 + 텍스처 검사로
  단순 사진 공격을 차단.
- **눈 깜박임 라이브니스** — 눈 영역의 엣지 에너지 변화로 **실제 깜박임**(개안→폐안→개안)을
  감지해 사진 공격을 차단(고개 돌리기/끄덕이기/움직임 옵션도 제공).
- **외형 변화 자동 반영(나이 등)** — 확신도 높은 인식에서만 템플릿을 조금씩 갱신하고
  오래된 것을 폐기하는 **적응형 템플릿**으로, 시간에 따른 얼굴 변화를 따라갑니다.
- **다국어(한국어/영어)** — 설정에서 UI 언어를 즉시 전환.
- **Windows Hello Face 안내** — `Login & Chrome` 탭에서 OS 로그인·크롬 비밀번호를 얼굴로
  쓰는 **지원되는 방법**(Windows Hello Face) 설정을 안내하고 IR 카메라 유무를 점검.
- **사용자 친화 GUI** — 단일 창 탭 UI(상태/PC 분석/등록/금고/로그인·크롬/설정/정보).
- **단일 EXE** — `build.bat` 하나로 `dist\VeriFace.exe` 생성.

## 🧭 솔직한 범위 안내 (꼭 읽어주세요)

이 프로그램은 **편의성·연구용 도구**이며, 인증 보안 제품 인증을 받은 솔루션이 아닙니다.
요청하신 목표 중 두 가지는 **보안·안전상의 이유로 의도적으로 다르게** 구현했습니다.

| 요청 | VeriFace의 구현 | 이유 |
|---|---|---|
| "크롬 비밀번호를 PIN 대신 얼굴로" | 크롬을 건드리지 않음. **Windows Hello Face** 설정을 안내 (크롬의 "Windows Hello로 비밀번호 채우기"가 Hello를 경유하므로 얼굴로 인증됨) + 자체 금고 제공 | 크롬 프로세스/저장소에 개입하는 것은 자격증명 탈취·인젝션 기법과 동일하여 수행하지 않음 |
| "Windows PIN 로그인을 얼굴로" | **OS 로그인 화면은 직접 대체하지 않음.** `Login & Chrome` 탭에서 **Windows Hello Face** 설정을 안내 | 진짜 OS 로그인은 커스텀 Credential Provider(미서명 DLL)의 영역 — 잠금(lockout) 위험 + RGB 웹캠만으로는 사진 스푸핑에 취약. Microsoft가 IR 카메라를 요구하는 이유 |

> **중요:** Windows Hello Face는 **IR 카메라**가 있어야 동작합니다. `Login & Chrome` 탭의
> `🔍 Check this PC`로 내 PC에 IR 카메라가 있는지 확인하세요. IR 카메라가 없으면 OS/크롬
> 얼굴 로그인은 이 PC에서 사용할 수 없고, **VeriFace 자체 얼굴 잠금·금고**만 사용 가능합니다.

**"얼굴이 확인되면 저장된 PIN을 자동 입력" 방식을 넣지 않은 이유**
- Windows 로그인/UAC는 **보안 데스크톱**에서 동작해 일반 프로그램이 키 입력을 보낼 수
  없습니다(악용 방지 설계) → 로그인 화면에서는 **기술적으로 불가능**.
- PIN을 저장해 두고 얼굴이 보이면 자동 입력하면, IR 없는 일반 웹캠은 **사진으로 속일 수**
  있어 "사진 한 장 → PIN 자동 입력 → 계정 탈취"가 됩니다 → **보안을 크게 약화**시키므로
  의도적으로 넣지 않았습니다. 정공법인 Windows Hello Face로 안내합니다.

- 라이브니스는 **기초 수준**입니다. 사진 공격은 막지만, 정교한 **영상 재생 공격**까지
  막지는 못합니다.
- 생체정보는 유출되면 바꿀 수 없습니다. **Windows 암호/PIN을 실질적 대체재로 유지**하세요.
- OS 로그인 연동을 원하면 Windows Hello(기본 제공)를 사용하거나, Credential Provider
  DLL 개발이 필요합니다(본 저장소 범위 밖).

## 🖥️ 설치 & 실행 (소스)

```bat
REM Python 3.10 ~ 3.12 (Windows)
pip install -r requirements.txt
python run.py
```

처음 실행하면: **PC 분석** → **모델 설치**(허가) → **등록(Enroll)** 순서로 진행하세요.

### 단일 EXE 빌드

```bat
build.bat
```

빌드가 끝나면 `dist\VeriFace.exe` 가 생성됩니다. 더블클릭으로 바로 실행됩니다.
(모델은 최초 실행 시 `PC 분석`에서 내려받으므로 EXE 자체는 가볍습니다.)

### 커맨드라인 (선택)

```bat
python -m veriface analyze     REM PC 분석 결과 출력
python -m veriface install     REM 모델 다운로드(확인 후)
python -m veriface enroll      REM 터미널에서 얼굴 등록
python -m veriface auth        REM 본인 확인 (종료코드 0=일치, 1=불일치)
```

## 🛠️ 문제 해결
- 실행 시 오류가 나면 `%LOCALAPPDATA%\VeriFace\veriface.log` 에 내용이 기록됩니다.
- 1.0.1에서 **윈도우(콘솔 없는) exe가 바로 종료되던 문제**(상대 import / stderr=None)를
  수정했습니다. 이전 exe를 쓰셨다면 릴리스에서 **최신 exe를 다시 받아주세요**.

## 🧩 동작 구조

```
veriface/
├─ __main__.py        진입점 (인자 없으면 GUI)
├─ app.py             CustomTkinter GUI (탭: 상태/분석/등록/금고/설정/정보)
├─ cli.py             analyze / install / enroll / auth 서브커맨드
└─ core/
   ├─ hardware.py     PC 분석 + 프로파일 추천
   ├─ model_manager.py 모델 선정·설치 확인·동의 기반 다운로드
   ├─ face_engine.py  YuNet 검출 + SFace 임베딩 (지연 로드/명시적 해제)
   ├─ liveness.py     능동 챌린지 기반 기초 라이브니스
   ├─ enrollment.py   다양한 각도 샘플 수집 세션
   ├─ authenticator.py 임계값 + 라이브니스 동시 충족 시에만 인증
   ├─ win_hello.py    Windows Hello Face 안내/IR 카메라 점검
   ├─ store.py        DPAPI 암호화 템플릿/금고 저장소
   ├─ crypto.py       ctypes 기반 DPAPI (pywin32 불필요)
   ├─ camera.py       지연 개방/확실한 해제 웹캠 래퍼
   ├─ config.py       비밀이 아닌 설정(JSON)
   └─ paths.py        %LOCALAPPDATA%\VeriFace 경로
```

### 인식 파이프라인
1. 프레임 캡처 → YuNet으로 얼굴·랜드마크 검출(프레임을 `det_size`로 축소해 속도 확보).
2. 가장 큰 얼굴을 SFace로 정렬·임베딩(128차원, L2 정규화).
3. 등록 임베딩들과 **코사인 유사도** 최대값을 임계값과 비교.
4. 동시에 **라이브니스 챌린지** 통과 여부 확인.
5. 둘 다 충족해야 인증 성공. 세션 종료 시 카메라·모델 즉시 해제.

### 저장 위치 / 완전 제거
모든 데이터는 `%LOCALAPPDATA%\VeriFace\` 한 폴더에만 생성됩니다.
해당 폴더를 삭제하면 템플릿·금고·설정·모델이 깨끗이 제거됩니다.

```
%LOCALAPPDATA%\VeriFace\
├─ config.json      설정(평문, 비밀 아님)
├─ templates.vfb    얼굴 임베딩 (DPAPI 암호화)
├─ vault.vfb        암호 금고 (DPAPI 암호화)
└─ models\*.onnx    다운로드된 AI 모델
```

## 🔒 개인정보 & 보안 요약
- **네트워크 사용은 모델 최초 다운로드뿐** (OpenCV Zoo). 그 외 전부 오프라인.
- 원본 얼굴 사진은 저장하지 않음(임베딩만).
- 저장 데이터는 DPAPI로 **현재 Windows 사용자 계정**에 묶여 암호화.
- 금고 내용은 얼굴 인증 후에만 메모리에서 복호화되어 표시되고, 미사용 시 자동 잠금.
- 클립보드로 복사한 비밀번호는 20초 후 자동 삭제.
